================================================================================
⚠️ IF SOMETHING GOES WRONG
================================================================================

ERROR: "Port 8000 already in use"
────────────────────────────────

SOLUTION:
  Close any other applications using port 8000
  OR
  Try a different port:

  cd C:\Users\Charitha Sadineni\OneDrive\Desktop\Games && python -m http.server 8001

  Then open: http://localhost:8001

ERROR: "python is not recognized"
──────────────────────────────────

SOLUTION:
  1. Make sure Python is installed
  2. Check: Open Command Prompt and type: python --version
  3. If nothing shows, install Python from python.org
  4. Restart Command Prompt
  5. Try the command again

ERROR: "Cannot find path"
─────────────────────────

SOLUTION:
  1. Check folder path is correct:
     C:\Users\Charitha Sadineni\OneDrive\Desktop\Games
  2. Open file explorer
  3. Navigate to that folder
  4. Verify it exists
  5. Try the command again from there

ERROR: Page won't load in browser
──────────────────────────────────

SOLUTION:
  1. Check Command Prompt shows: "Serving HTTP on..."
  2. Wait 3 seconds
  3. Refresh browser: Ctrl + R
  4. Try: http://localhost:8000 again
  5. If still broken, close browser and reopen
  6. Try different browser

ERROR: No sound in games
────────────────────────

SOLUTION:
  1. Check system volume
  2. Check browser volume
  3. Check browser settings allow audio
  4. Try different browser
  5. Game works fine without audio anyway!

CAN'T FIND ASSIGNED GAME AS STUDENT:
─────────────────────────────────────

SOLUTION:
  1. Make sure teacher assigned the game
  2. Use EXACT same student name (case-sensitive)
  3. Use EXACT same roll number
  4. Refresh page: F5
  5. Try again

  Close browser → all games/scores still there
  Data persists automatically

TIP 5: You can close browser, keep server running
  Browser closed? No problem!
  Server keeps running
  Just reopen browser and go to http://localhost:8000

TIP 6: Multiple users on same computer
  Open multiple browsers
  One can be teacher, others students
  All connect to same portal
