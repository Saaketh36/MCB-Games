🔧 TROUBLESHOOTING
================================================================================

ERROR: "File not found"
  → Make sure file path is correct
  → Try: \i 'C:/Users/Charitha Sadineni/OneDrive/Desktop/Games/CREATE-DATABASE-PRODUCTION.sql'

ERROR: "Permission denied"
  → Make sure user has privileges
  → Run: GRANT ALL PRIVILEGES ON DATABASE myclassboard_games TO myclassboard_user;

ERROR: "Role does not exist"
  → User not created
  → Create with: CREATE USER myclassboard_user WITH PASSWORD 'your_password';

ERROR: "Database does not exist"
  → Database not created
  → Create with: CREATE DATABASE myclassboard_games;

ERROR: "Duplicate key value"
  → Data already exists (from previous run)
  → Check with: SELECT COUNT(*) FROM classes;

EXECUTION TAKES TOO LONG:
  → Normal for first run
  → Wait for completion message

NO OUTPUT AFTER RUNNING:
  → Check with: SELECT COUNT(*) FROM classes;
  → If 8 rows → Success!
