HOW IT WORKS FOR STUDENTS
================================================================================

WORKFLOW:
1. Student opens portal at http://localhost:8000
2. Enters name and roll number
3. Clicks on game assigned by teacher
4. During game:
   ✓ Hears audio feedback (claps for correct, buzzer for wrong)
   ✓ Sees points tracker widget in top-right
   ✓ Real-time score updates
5. At game end:
   ✓ Shows final score (X / 50 points)
   ✓ Shows correct answer count (X / 5)
   ✓ Shows emoji feedback (🏆 / 👍 / 💪)
   ✓ Scores saved to localStorage

POINTS CALCULATION:
- Each question: 10 points for correct, 0 for wrong
- All 5 correct: 50 points (Perfect! 🏆)
- 4 correct: 40 points (Great! 👍)
- 3-2 correct: 30 points (Good!)
- <2 correct: <30 points (Keep Practicing! 💪)

AUDIO FEEDBACK:
- Correct: 3 claps with increasing pitch (ding-ding-ding)
- Wrong: Buzzer that sweeps down and up (beep-beep-beep)
- Perfect Game: Celebration melody plays at end

TECHNICAL ARCHITECTURE
================================================================================

AUDIO SYSTEM:
┌─────────────────────────────────────────┐
│ audioGenerator Class (Web Audio API)    │
├─────────────────────────────────────────┤
│ .playCorrectSound()   → 3 clap tones    │
│ .playWrongSound()     → buzzer sweep    │
│ .playCelebrationSound()→ 5 note melody  │
│ .initAudio()          → context setup   │
└─────────────────────────────────────────┘
  ↓ Uses: window.AudioContext (web standard)

POINTS TRACKER:
┌─────────────────────────────────────────┐
│ PointsTracker Class (DOM Manipulation) │
├─────────────────────────────────────────┤
│ .createTracker()      → Build HTML/CSS  │
│ .addCorrectPoints()   → +10 points      │
│ .addWrongAnswer()     → +0 points       │
│ .updateDisplay()      → Refresh widget  │
│ .getFinalScore()      → Return total    │
│ .reset()              → Reset to 0      │
└─────────────────────────────────────────┘
  ↓ Uses: DOM manipulation + CSS styling

DATA FLOW:
Student Plays Game
  ↓
Selects Answer
  ↓
Checks Answer
  ├─→ Correct?
  │   ├─→ audioGenerator.playCorrectSound()
  │   └─→ pointsTracker.addCorrectPoints()
  │
  └─→ Wrong?
      ├─→ audioGenerator.playWrongSound()
      └─→ pointsTracker.addWrongAnswer()
  ↓
Display Feedback
  ↓
Widget Updates in Real-Time
  ↓
Game Ends
  ├─→ Get Final Score
  ├─→ Save to localStorage
  └─→ Show Results Screen
