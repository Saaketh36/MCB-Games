🛡️ FIREWALL CONFIGURATION:

Windows Firewall (Allow Streamlit):

1. Open Windows Defender Firewall
2. Click "Allow an app through firewall"
3. Click "Change settings"
4. Click "Allow another app"
5. Browse and select: python.exe
6. Click "Add"
7. Make sure ports 8501 and 8000 are allowed

OR Command Line:
  netsh advfirewall firewall add rule name="Streamlit" ^
  dir=in action=allow program="C:\path\to\python.exe" ^
  protocol=tcp localport=8501

📞 TROUBLESHOOTING SECURITY:

Issue: "Cannot access on another computer"
Solution: Check IP with ipconfig, firewall rules, same network

Issue: "Port already in use"
Solution: Kill process on port: netstat -ano | findstr :8501

Issue: "Connection refused"
Solution: Check if Streamlit is running, correct port number

Issue: "Slow performance"
Solution: Check network, reduce student load, optimize game files

Issue: "Data not saving"
Solution: Check file permissions, disk space, database connection
