# 🚀 QUICK START GUIDE

## ⏱️ 30-Second Setup

**Your MyClassboard Games platform is READY!** Just run the server:

```bash
python -m http.server 8000
```

Then open: **http://localhost:8000/**

---

## 👨‍🏫 FOR TEACHERS

### **Assign a Game in 5 Steps:**

1. **Click "TEACHER"** button
2. **Select Path**: Class → Subject → Skill → Game
3. **Enter Info**: Student Name & Roll Number
4. **Set Deadline** (optional)
5. **Click "ASSIGN"** ✅

**Example Workflow:**
- Class I → English → Listening → "Listen & Do Adventure"
- Student: "Rahul Sharma"
- Roll No: 101
- Deadline: Tomorrow
- Click ASSIGN

### **See Results:**
- Scroll down to "Track Results" table
- Click "REFRESH" to update status
- Status shows: ⏳ Pending or ✅ Completed
- Score shows: 10/10, 7/10, or 5/10 points

---

## 👨‍🎓 FOR STUDENTS

### **Play a Game in 3 Steps:**

1. **Click "STUDENT"** button
2. **See assigned games** (teacher must assign first)
3. **Click "PLAY"** → Game opens → Play → Score saves automatically ✅

**Important**: Students can ONLY see games their teacher assigned!

## 🐛 **TROUBLESHOOTING**

### **"Game not showing in student portal"**
→ Teacher must ASSIGN the game first (role = Teacher, select game, click ASSIGN)

### **"Score not saving"**
→ Check browser console (F12), allow localStorage

### **"Sound not playing"**
→ Check browser sound settings, allow audio

### **"Game keeps showing 'Pending'"**
→ Student must COMPLETE the game (answer correctly) to update status
