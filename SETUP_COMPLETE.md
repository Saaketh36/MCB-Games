## 🔧 Customization

### **Want to Change Game Questions?**
1. Open any game file (e.g., simple_addition.html)
2. Find the `quizData` section around line 350
3. Edit questions, options, and correct answers
4. Save the file
5. Refresh browser - changes take effect immediately

### **Want to Create New Games?**
1. Copy `GAME_TEMPLATE.html`
2. Rename to your game name
3. Update `gameConfig` (title, class, skill)
4. Add 5 questions with options and correct answers
5. Save and it's ready to play!

See `CREATE_GAMES_GUIDE.md` for detailed instructions.

## 🆘 Troubleshooting

### **Games Not Loading?**
- Check Flask server is running: http://localhost:5000/game_index.html
- If not, run: `python app.py` in Games folder
- Wait 5 seconds for server to start

### **Want to Add More Games?**
- Use `GAME_TEMPLATE.html` as a template
- Follow `CREATE_GAMES_GUIDE.md` instructions
- All new games inherit the complete feature set

### **Database Issues?**
- Check PostgreSQL is running
- Verify .env file has correct credentials
- Run: `python app.py` to reinitialize
