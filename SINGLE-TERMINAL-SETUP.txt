================================================================================
🔧 HOW npm run dev:full WORKS
================================================================================

The command: npm run dev:full

Executes: http-server -p 8000 -c-1 -o index.html & python app.py

Breakdown:
  http-server -p 8000 -c-1 -o index.html
    └─ Start web server on port 8000
    └─ Disable caching
    └─ Auto-open index.html in browser

  &
    └─ Run next command in parallel (same terminal)

  python app.py
    └─ Start Flask API server on port 5000
    └─ Runs in background of same terminal

================================================================================
📋 TROUBLESHOOTING - SINGLE TERMINAL
================================================================================

"Port 8000 already in use"
  → Kill process: taskkill /PID <PID> /F
  → Or try: npm run start:full

"Port 5000 already in use"
  → Kill Flask process
  → Or wait and try again

"Python not found error"
  → Python not installed
  → Install from python.org
  → Restart Command Prompt

"http-server not found"
  → Run: npm install
  → Then: npm run dev:full

"Browser won't open"
  → Manually open: http://localhost:8000
  → Or refresh: Ctrl + R

"Concurrently not found (if using npm run all)"
  → Run: npm install
  → This installs concurrently package
  → Then try: npm run all
