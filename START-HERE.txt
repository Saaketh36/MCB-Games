================================================================================
⚠️ COMMON ISSUES
================================================================================

ISSUE: "Port 8000 already in use"
FIX: Change port to 8001
  python -m http.server 8001
  Then open: http://localhost:8001

ISSUE: "python not found"
FIX: Install Python from python.org
  Then check: python --version

ISSUE: Portal doesn't load
FIX:
  1. Check terminal shows "Serving HTTP..."
  2. Wait 3 seconds
  3. Try refreshing: Ctrl + R
  4. Try different browser

ISSUE: Audio not working
FIX:
  1. Check system volume
  2. Check browser volume
  3. Try different browser
  Game works fine without audio!

ISSUE: Can't see assigned games as student
FIX:
  1. Make sure you assigned the game as teacher
  2. Use EXACT same name (case-sensitive)
  3. Refresh page: F5
  4. Try again
