## 🔧 HOW TO CREATE MORE GAMES

### Quick Steps:
1. Copy one of the 5 working games (e.g., `simple-addition.html`)
2. Rename to match the game (e.g., `subtraction-basics.html`)
3. Modify the game content/logic
4. Add to `playAssignedGame()` function in index.html
5. Upload and test

### Example: Create "Subtraction Basics"
```javascript
// In index.html, add to playAssignedGame() function:
'Subtraction Basics': 'subtraction-basics.html',

// Then create subtraction-basics.html with:
// - Subtraction problems instead of addition
// - Same UI, sounds, animations, scoring system
// - Add student name & skill display from URL params
```

## 📋 GAME TEMPLATE

All games follow this structure:

```html
<!DOCTYPE html>
<html>
<head>
    <title>[Game Name]</title>
    <style>
        /* Professional UI, Glass morphism design */
        /* Responsive, mobile-friendly */
    </style>
</head>
<body>
    <div class="container">
        <header>
            <h1>🎮 [Game Name]</h1>
            <p id="playerInfo"></p> <!-- Shows student name & skill -->
        </header>
        
        <div class="game-area">
            <!-- Game content here -->
        </div>
    </div>

    <script>
        function init() {
            // Get student info from URL
            const params = new URLSearchParams(window.location.search);
            document.getElementById("playerInfo").innerText = 
                `📚 ${params.get("student")} • Skill: ${params.get("skill")}`;
            
            // Game logic here
        }
        
        function saveCompletion(score) {
            // Save to localStorage
            const assignments = JSON.parse(localStorage.getItem("mcb_assignments"));
            // Update status & score
            localStorage.setItem("mcb_assignments", JSON.stringify(assignments));
        }
        
        window.addEventListener('load', init);
    </script>
</body>
</html>
```
