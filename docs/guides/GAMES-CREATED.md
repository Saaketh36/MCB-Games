## 🚀 HOW TO ACCESS

### **Portal** 
👉 **http://localhost:8000/**

### **Teacher Features**
1. Click "TEACHER" button
2. Select Class → Subject → Skill → Game
3. Enter student name and roll number
4. Set deadline
5. Click "ASSIGN"
6. Track results in table

### **Student Features**
1. Click "STUDENT" button
2. See assigned games
3. Click "PLAY"
4. Complete game
5. Automatic score save
