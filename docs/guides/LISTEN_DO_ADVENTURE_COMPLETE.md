## How It Works

1. **Student clicks on activity** → Loads video
2. **Video plays** → Shows action steps (12-15 seconds)
3. **Student completes instructions** → Following the video
4. **Questions appear** → With visual images for each question
5. **Student answers** → Based on video content
6. **Scores points** → For correct answers
