## 📊 Technical Details:

### Background CSS:
```css
body {
    background: url('images/listen-do-adventure-bg.jpg') no-repeat center/cover fixed;
    background-attachment: fixed;
}
```

### Container CSS:
```css
.container {
    background: rgba(255, 255, 255, 0.95);
    backdrop-filter: blur(5px);
    border-radius: 30px;
    box-shadow: 0 10px 40px rgba(0, 0, 0, 0.25);
}
```

### Features:
- ✅ `no-repeat` - Image shows once
- ✅ `center/cover` - Centered and covers entire background
- ✅ `fixed` - Stays in place while scrolling
- ✅ `rgba(255, 255, 255, 0.95)` - 95% white, 5% transparent
- ✅ `blur(5px)` - Glass effect
- ✅ Enhanced shadow for depth
