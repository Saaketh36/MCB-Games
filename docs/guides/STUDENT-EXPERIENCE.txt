STEP 2: STUDENT SELECTS ANSWER

- Other options remain normal

================================================================================
STEP 3: STUDENT CLICKS "CHECK ANSWER"
================================================================================

ACTION: Student clicks [Check Answer] button

AUDIO FEEDBACK: 🔊
- 3 ascending claps play:
  • First clap: Low pitch (800Hz) - "ding"
  • Second clap: Medium pitch (900Hz) - "ding"
  • Third clap: High pitch (1000Hz) - "ding"
- Sound plays for ~0.6 seconds
- Each clap is ~120ms long
- Claps separated by 250ms gaps

VISUAL FEEDBACK: ✅
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│                   ┌─────────────────┐                        │
│                   │  ✅ CORRECT!    │                        │
│                   │  +10 POINTS     │                        │
│                   └─────────────────┘                        │
│            (message bounces with animation)                  │
│                                                              │
│            (message auto-disappears after 1.5s)             │
└──────────────────────────────────────────────────────────────┘

BUTTON CHANGE:
- [Check Answer] button hides
- [Next Problem] button appears

WIDGET UPDATES IN REAL-TIME: 📊
┌─────────────────────────┐
│  📊 STUDENT PROGRESS    │
├─────────────────────────┤

- Green border (#4caf50)
- Light green background
- Animation effect (pops/bounces)

================================================================================
STEP 4: STUDENT CLICKS "NEXT PROBLEM"
================================================================================

ACTION: Student clicks [Next Problem]

SCREEN UPDATES:
- New problem appears: "5 + 2 = ?"
- New answer options appear (randomized)
- Progress bar updates: "Problem 2 of 5"
- Widget retains points from previous question
- Check Answer button appears again

STUDENT CAN REPEAT STEPS 2-4 for remaining 3 problems

================================================================================

  • Sweeps back up to 400Hz (higher pitch) over 150ms
  • Total duration: 350ms
- Sound pattern: "beep-beep-beep" (down then up)
