📋 COMPLETE STEP-BY-STEP GUIDE
================================================================================

STEP 1: Check Node.js Installation
──────────────────────────────────

Open Command Prompt:
  Press: Windows Key + R
  Type: cmd
  Press: Enter

Check if Node.js installed:
  npm --version

If you see a version number (like 9.0.0) → Go to STEP 2

If you see "command not found" → INSTALL NODE.JS FIRST:
  1. Go to: https://nodejs.org
  2. Download LTS version
  3. Run installer (click Next, Next, Install)
  4. Restart Command Prompt
  5. Try: npm --version (should work now)

STEP 2: Navigate to Project Folder
──────────────────────────────────

Paste this command:

cd C:\Users\Charitha Sadineni\OneDrive\Desktop\Games

Press: Enter

You should see:
  C:\Users\Charitha Sadineni\OneDrive\Desktop\Games>

STEP 3: Install Dependencies (First Time Only)
──────────────────────────────────────────────

Type this command:

npm install

Press: Enter

Wait for it to finish. You'll see:
  added X packages

This creates the node_modules folder with http-server.

STEP 4: Start Development Server
────────────────────────────────

Type this command:

npm run dev

Press: Enter

You'll see:
  Starting up http-server, serving ./
  Available on:
    http://127.0.0.1:8000
    http://localhost:8000

Browser will AUTOMATICALLY OPEN!

If browser doesn't open, manually open:
  http://localhost:8000

STEP 5: You'll See
──────────────────

🎮 MyClassboard Games Portal

With 2 buttons:
  🏫 TEACHER
  👨‍🎓 STUDENT

✅ SYSTEM IS RUNNING!

STEP 6: Use the Portal!
──────────────────────

Click TEACHER button to:
  • Select Class, Subject, Skill, Game
  • Assign games to students
  • View results

Click STUDENT button to:
  • See your assigned games
  • Play games
  • Hear audio feedback
  • Track points

================================================================================
❓ QUICK TROUBLESHOOTING
================================================================================

"npm not found"
  → Install Node.js from nodejs.org
  → Restart Command Prompt

"Port 8000 already in use"
  → Kill process: taskkill /PID <PID> /F
  → Or change port in package.json and run: npm run dev

"node_modules not found"
  → Run: npm install
  → Then: npm run dev

"Browser won't open"
  → Manually open: http://localhost:8000
  → Or refresh: Ctrl + R

"Server takes long time"
  → Normal - just wait
  → When you see "http://localhost:8000" it's ready

"Can't see assigned games as student"
  → Make sure teacher assigned it
  → Use EXACT same name and roll number
  → Refresh: F5
