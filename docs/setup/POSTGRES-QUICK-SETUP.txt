🚀 QUICK START (15 minutes)
================================================================================

STEP 1: Open pgAdmin (2 minutes)
────────────────────────────────
1. Search for "pgAdmin" on your computer
2. Open pgAdmin (or go to http://localhost:5050)
3. Login with your pgAdmin credentials
4. If first time:
   - Setup admin password
   - Create default server connection

STEP 2: Create Database (3 minutes)
────────────────────────────────
1. Right-click "Databases" → Create → Database
2. Name: myclassboard_games
3. Owner: postgres (default)
4. Encoding: UTF8
5. Click "Save"
6. You should see new database in list

STEP 3: Create Database User (2 minutes)
────────────────────────────────
1. In pgAdmin, go to: Servers → PostgreSQL 18 → Login/Group Roles
2. Right-click → Create → Login/Group Role
3. General Tab:
   - Name: myclassboard_user
4. Definition Tab:
   - Password: YOUR_SECURE_PASSWORD (remember this!)
   - Confirm password: (same)
5. Privileges Tab:
   - Can login? YES
   - Superuser? NO (for security)
6. Click "Save"

STEP 4: Grant Permissions (2 minutes)
────────────────────────────────
1. Right-click on "myclassboard_games" database
2. Go to: Properties → Security (or Privileges)
3. Click "+" button
4. Select: myclassboard_user
5. Grant: ALL
6. Click "Save"

STEP 5: Create Tables (3 minutes)
────────────────────────────────
1. In pgAdmin, right-click database → Query Tool
2. Copy and paste ALL the SQL from "DATABASE-SETUP-GUIDE.md"
   (Section: Schema & Tables - Step 1)
3. Click "Execute" (play button)
4. You should see: "Query returned successfully with no result"

STEP 6: Verify Tables (2 minutes)
────────────────────────────────
1. In pgAdmin, expand: myclassboard_games → Schemas → public → Tables
2. You should see these 8 tables:
   ✅ students
   ✅ classes
   ✅ subjects
   ✅ skills
   ✅ games
   ✅ assignments
   ✅ scores
   ✅ audio_feedback

import os
from dotenv import load_dotenv

load_dotenv()

try:
    conn = psycopg2.connect(
        host=os.getenv('DB_HOST'),
        port=os.getenv('DB_PORT'),
        database=os.getenv('DB_NAME'),
        user=os.getenv('DB_USER'),
        password=os.getenv('DB_PASSWORD')
    )
    print("✅ Database connected successfully!")
    cursor = conn.cursor()
    cursor.execute("SELECT * FROM students;")
    print("✅ Can query students table!")

    conn.close()

    print(f"❌ Error: {e}")

📊 DATABASE STRUCTURE
================================================================================

TABLES (8 total):

1. students
   - Stores student information
   - Fields: id, name, roll_number, class, email, phone, timestamps

2. classes
   - Class levels (I, II, III, ... VIII)
   - Fields: id, name, description, created_at

3. subjects
   - Subjects per class (English, Math, Science)
   - Fields: id, name, class_id, created_at

4. skills
   - Skills per subject (Addition, Fractions, etc.)
   - Fields: id, name, description, subject_id, class_id, created_at

5. games
   - Games linked to skills
   - Fields: id, name, description, skill_id, game_type, file_path, max_score

6. assignments
   - Games assigned to students
   - Fields: id, student_id, game_id, status, deadline, timestamps

7. scores
   - Student scores for games played
   - Fields: id, assignment_id, student_id, score, correct_answers, timestamps

8. audio_feedback
   - Audio feedback logs
   - Fields: id, score_id, feedback_type, frequency, duration

9. analytics
   - Student performance analytics
   - Fields: id, student_id, games_played, average_score, total_time_spent

================================================================================
🐛 TROUBLESHOOTING
================================================================================

ISSUE: "Could not connect to server"
FIX:
1. Open Services (Windows + R → services.msc)
2. Find: postgresql-x64-18
3. Right-click → Start
4. Wait 30 seconds
5. Try connecting again

ISSUE: "Role does not exist"
FIX:
1. Verify user created: myclassboard_user
2. In pgAdmin: Servers → PostgreSQL 18 → Login/Group Roles
3. Should show: myclassboard_user
4. If missing, recreate user

ISSUE: "Database does not exist"
FIX:
1. In pgAdmin, refresh Databases
2. Should show: myclassboard_games
3. If missing, recreate database

ISSUE: "Permission denied"
FIX:
1. In pgAdmin, right-click database
2. Go to Properties → Security
3. Grant myclassboard_user → ALL privileges
4. Click Save

ISSUE: "psycopg2 not found"
FIX:
pip install psycopg2-binary==2.9.9

ISSUE: "Connection refused"
FIX:
1. Check password is correct in .env
2. Check host is "localhost" (not 127.0.0.1)
3. Verify port 5432 is not blocked
4. Restart PostgreSQL service
