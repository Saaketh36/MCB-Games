# ⚡ Quick Start Guide - 5 Minutes to First Exam

## 🎯 Start Server
```bash
npm run dev
```
OR
```bash
python app.py
```

Then open: **http://localhost:5000**

---

## 👨‍🏫 Teacher: Generate PIN (2 minutes)

1. **LEFT SIDE** - "Teacher Dashboard"
2. Select dropdowns in order:
   - Class: **Class I**
   - Subject: **English**
   - Skill: **Listening – Following Instructions**
   - Activity: **Listen & Do Adventure**
3. Click: **🔑 Generate PIN**
4. Copy the PIN (e.g., **474738**)

✅ PIN Ready! Share with students.

---

## 👨‍🎓 Student: Take Exam (5-10 minutes)

1. **RIGHT SIDE** - "Student Portal"
2. Enter:
   - Name: **Aman**
   - PIN: **474738** (from teacher)
3. Click: **📖 Start Exam**

### Answer Each Question:

**Story (if shown):**
- Read or click 🔊 Listen
- Click: **✓ I've Read - Show Questions**

**Each Question:**
- Click 🔊 **Listen to Question** (to hear)
- Select answer (for sequence, click in order 1, 2, 3...)
- Click **Next →**

**Last Question:**
- Click **✓ Ready to Submit**
- Click **✓ Submit Exam**

### See Results:
- 🎊 Confetti falls
- 🔔 Sound plays
- Shows: **8/10 (80%)**
- See which answers were wrong
- Click **🚪 Quit & Exit**

---

## 👨‍🏫 Teacher: Check Results (1 minute)

1. Scroll down on LEFT SIDE
2. Click: **🔄 Refresh Results**
3. See table with all student scores

---

## 🔐 Important: PIN Security

**First time:** ✅ PIN works
**Second time:** ❌ PIN LOCKED (cannot reuse)

→ Teacher must generate **NEW PIN** for each attempt

---

## 📋 Question Types

**Sequence Order:**
- Click in correct order: 1st, 2nd, 3rd...

**Multiple Choice:**
- Click one option

**Text Input:**
- Type your answer
