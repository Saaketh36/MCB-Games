🎮 HOW TO USE
═══════════════════════════════════════════════════════════════════════════════

TEACHER WORKFLOW:
1. Open http://localhost:8000/
2. Click TEACHER button
3. Select Class (I-VIII)
4. Select Subject (English, Math, Science)
5. Select Skill (based on class)
6. Select Game (4 games per skill)
7. Enter student name & roll number
8. Click ASSIGN
9. View results in table

STUDENT WORKFLOW:
1. Click STUDENT button
2. See assigned games
3. Click PLAY to start game
4. Complete game
5. Score auto-saves
6. Status updates to "Completed"

PYTHON API USAGE:
Get available games:
GET http://localhost:5000/api/available-games

Create assignment (example with curl):
curl -X POST http://localhost:5000/api/assignments \
  -H "Content-Type: application/json" \
  -d '{
    "student": "Priya",
    "roll": "301",
    "game": "Fraction Basics",
    "class": "III",
    "subject": "Mathematics",
    "skill": "Fractions"
  }'

Get all assignments:
GET http://localhost:5000/api/assignments

Complete assignment with score:
POST http://localhost:5000/api/assignments/<id>/complete
{"score": 10}

Get class report:
GET http://localhost:5000/api/reports/class/III

Get skill report:
GET http://localhost:5000/api/reports/skill/Multiplication

📊 API ENDPOINTS
═══════════════════════════════════════════════════════════════════════════════

CURRICULUM APIs:
GET    /api/curriculum           - Get all curriculum data
GET    /api/subjects/<class>     - Get subjects for class
GET    /api/skills/<class>/<sub> - Get skills for class/subject
GET    /api/games/<skill>        - Get games for skill
GET    /api/available-games      - Get games with HTML files

ASSIGNMENT APIs:
GET    /api/assignments          - Get all assignments
POST   /api/assignments          - Create new assignment
GET    /api/assignments/<id>     - Get specific assignment
POST   /api/assignments/<id>/complete - Mark as complete

STUDENT APIs:
GET    /api/students             - Get all students
GET    /api/students/<roll>/assignments - Get student assignments

REPORTING APIs:
GET    /api/reports/class/<class> - Get class performance report
GET    /api/reports/skill/<skill> - Get skill performance report

🐛 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Issue: "ModuleNotFoundError: No module named 'flask'"
Fix: pip install Flask==2.3.0

Issue: "Port 5000 already in use"
Fix: netstat -ano | findstr :5000
     taskkill /PID <PID> /F
     Or change port in app.py

Issue: "CORS error"
Fix: CORS already enabled in app.py. Ensure both servers running:
     - Python: http://localhost:5000
     - HTML: http://localhost:8000

Issue: "assignments.json not found"
Fix: Will be created automatically on first run

Issue: "Games not showing in portal"
Fix: Ensure all 7 HTML game files exist in same directory as index.html
