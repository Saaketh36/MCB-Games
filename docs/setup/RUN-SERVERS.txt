================================================================================
⚠️ TROUBLESHOOTING
================================================================================

ERROR: "Port already in use"
  └─ Solution: Another app is using the port
  └─ Fix: Change WEB_PORT or API_PORT in .env
  └─ Example: Change "8000" to "8001" in .env

ERROR: "python: command not found"
  └─ Solution: Python not installed or not in PATH
  └─ Fix: Install Python or add to PATH
  └─ Test: python --version

ERROR: "Module not found"
  └─ Solution: Python packages not installed
  └─ Fix: pip install -r requirements.txt
  └─ Wait for installation to complete

ERROR: "Connection refused" in browser
  └─ Solution: Server not running
  └─ Fix: Check Terminal 1 shows "Serving HTTP..."
  └─ Wait: Servers take 2-3 seconds to start

ERROR: "CORS error" in console
  └─ Solution: API not running
  └─ Fix: Check Terminal 2 shows "Running on..."
  └─ Ensure both servers are running

ERROR: ".env not found" or database errors
  └─ Solution: Configuration issue
  └─ Fix: Check .env file exists in correct location
  └─ Path: C:\Users\Charitha Sadineni\OneDrive\Desktop\Games\.env

💻 RECOMMENDED SETUP (Windows)
================================================================================

Using Command Prompt or PowerShell:

Option 1: Manual (Recommended for beginners)
  1. Open Terminal 1: Run Python web server
  2. Open Terminal 2: Run Python API server
  3. Keep both open side by side
  4. Easy to see error messages

Option 2: Using Task Scheduler (Advanced)
  1. Create batch files for each server
  2. Schedule to run on startup
  3. Servers start automatically
  4. Less manual work

Option 3: Using VS Code Terminals (Recommended for developers)
  1. Open project in VS Code
  2. Open Terminal 1: python -m http.server 8000
  3. Open Terminal 2: python app.py
  4. Both visible in same window
  5. Easy to debug

Option 4: Using PowerShell
  1. Run: Set-ExecutionPolicy -ExecutionPolicy RemoteSigned
  2. Create: start-servers.ps1
  3. Run: .\start-servers.ps1
