📝 TROUBLESHOOTING QUICK REFERENCE
================================================================================

ISSUE: "GEMINI_API_KEY not configured"
SOLUTION:
  1. Check .env file exists: notepad .env
  2. Verify GEMINI_API_KEY=YOUR_KEY (not empty)
  3. Get key from: https://aistudio.google.com/app/apikey
  4. Restart servers

ISSUE: "Port 8000 already in use"
SOLUTION:
  1. Change WEB_PORT in .env to 8001
  2. Restart server
  3. Access at: http://localhost:8001

ISSUE: "Port 5000 already in use"
SOLUTION:
  1. Change API_PORT in .env to 5001
  2. Restart server
  3. Update CORS_ORIGINS in .env

ISSUE: "python-dotenv not found"
SOLUTION:
  pip install python-dotenv==1.0.0

ISSUE: "Audio not working"
SOLUTION:
  1. Check system volume
  2. Check browser volume
  3. Allow autoplay in browser
  4. Open Console (F12) for errors

ISSUE: "Can't connect to API"
SOLUTION:
  1. Verify Terminal 2 (API server) is running
  2. Check for errors in Terminal 2
  3. Verify port 5000 is not blocked
  4. Restart API server
